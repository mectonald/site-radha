# Site Radha Joias

Demonstração da loja online própria da Radha Joias: Moissanite, Prata 925 e Semijoias.

## O que tem aqui
- `index.html`: o site completo (abertura animada, coleções, catálogo com filtros, apps de cliente e revendedora, serviços e cadastro).
- `img/`: fotos das joias do catálogo.

## Como ver
Abra `index.html` no navegador, ou ative o GitHub Pages em Settings → Pages → branch `main`, pasta `/ (root)`.

Itens entre colchetes, como [VALOR] e [CNPJ], são espaços para preencher com os dados reais.
